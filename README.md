# Voyage Europa — шаблон сайта экскурсий по Европе

Одностраничный (SPA) шаблон витрины экскурсий с хеш-роутингом, корзиной и поиском. Полностью статический — деплоится в любой хостинг статики или открывается локально.

## Наполнение

- **8 стран**: Испания, Италия, Венгрия, Болгария, Швейцария, Франция, Германия, Чехия
- **80 городов** (по 10 на страну)
- **528 экскурсий** (в среднем 6–7 на город) с описаниями, длительностью, ценами в евро, рейтингами и отзывами
- Все цены и описания взяты из открытых источников (GetYourGuide, Viator, Tripster) и служат демо-данными

## Как запустить

```bash
# любой статический сервер, например:
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

Или просто открыть `index.html` через `file://` (корзина сохраняется в localStorage).

## Файлы

- `index.html` — каркас страницы
- `css/style.css` — дизайн-система (палитра терракота + кремовый, Playfair Display + Manrope)
- `js/app.js` — SPA-роутер, рендер страниц, корзина, генератор SVG-обложек
- `js/data.js` — весь контент (страны/города/экскурсии)

## Как редактировать контент

Открыть `js/data.js`. Структура:

```js
DATA.countries.push({
  id: 'italy', name: 'Италия', flag: '🇮🇹',
  description: '…',
  cities: [
    { id: 'rome', name: 'Рим', description: '…', excursions: [
      { id: 'rom-1', name: '…', description: '…',
        duration: '3.5 часа', price: 72, rating: 4.9, reviews: 4321 },
    ]},
  ]
});
```

Каждой экскурсии автоматически генерируется уникальная SVG-обложка на основе её `id` — гарантирует, что дизайн карточек не поплывёт даже без реальных фото.

## Роуты

- `#/` — главная
- `#/country/<id>` — страна и её города
- `#/city/<countryId>/<cityId>` — город и его экскурсии
- `#/search/<query>` — поиск по всем экскурсиям

## Что можно доделать

- Подключить реальные фото (Unsplash API, собственный CDN) — заменить `svgPostcard()` на `<img src="…">`
- Прикрутить платёжный шлюз (Stripe, YooKassa) к кнопке «Оформить бронирование»
- Форма выбора даты и количества человек в модалке карточки
- SSR/статическая генерация страниц под SEO (Astro, Next.js)
